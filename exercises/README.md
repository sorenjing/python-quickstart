# 00～05 章节练习与参考答案

建议先看各章节的题目，**独立写出答案后再核对**。这里的例题为本仓库原创的基础练习，并非任何高校的真实考试原题。

## 00｜Python 入门

**1. 输出文字**

~~~python
print("期末加油")
~~~

**2. 判断输出**

不相同：`print(2 * 3)` 输出数字 `6`；`print("2 * 3")` 输出字符串内容 `2 * 3`。

## 01｜基础语法

**1. 输入姓名与两门成绩**

~~~python
name = input("姓名：")
score1 = int(input("第一门成绩："))
score2 = int(input("第二门成绩："))
print(name, score1 + score2)
~~~

**2. 大小写**

`name` 与 `Name` 是两个不同的变量，Python 区分大小写。

**3. 连续赋值**

`x` 最终为 `7`。

## 02｜数据类型与运算符

**1. 除法与取余**

`9 / 2` 得到 `4.5`；`9 // 2` 得到 `4`；`9 % 2` 得到 `1`。

**2. 运算优先级**

`2 ** 3 + 4 * 2` 得到 `16`。

**3. 比较不同类型**

`"10" == 10` 得到 `False`。

**4. 矩形面积**

~~~python
width = int(input("宽："))
height = int(input("高："))
print(width * height)
~~~

## 03｜条件与循环

**1. 求 1～100 的整数和**

~~~python
total = 0
for i in range(1, 101):
    total += i
print(total)  # 5050
~~~

**2. 输出偶数**

~~~python
for i in range(2, 11, 2):
    print(i)
~~~

输出 `2、4、6、8、10`（各占一行）。

**3. 判断循环输出**

结果是 `7`。`range(1, 5)` 依次得到 1、2、3、4；当 `i == 3` 时跳过累加，因此 `1 + 2 + 4 = 7`。

## 04｜字符串

**1. 字符串切片**

`s = "abcdef"` 时：

- `s[1:5:2]` 为 `"bd"`。
- `s[-2:]` 为 `"ef"`。
- `s[::-1]` 为 `"fedcba"`。

**2. 判断回文**

~~~python
s = input("请输入字符串：")
print(s == s[::-1])
~~~

这里是严格按原始字符比较，大小写和空格都会影响结果。

**3. 清理与拆分**

~~~python
s = "  86,92,75  "
print(s.strip().split(","))  # ['86', '92', '75']
~~~

## 05｜组合数据类型

**1. 列表长度**

`append(40)` 后有四个元素，`len(a)` 为 `4`。

**2. 单元素元组**

`(5)` 是 `int`；`(5,)` 才是 `tuple`。

**3. 集合去重**

~~~python
nums = [1, 2, 2, 3, 3]
unique = set(nums)
print(len(unique))  # 3
~~~

集合元素顺序不应作为判断依据。

**4. 更新字典**

~~~python
scores = {"小王": 80, "小李": 95}
print(scores["小李"])  # 95
scores["小王"] = 85
print(scores)  # {'小王': 85, '小李': 95}
~~~

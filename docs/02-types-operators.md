# 02｜数据类型与运算符

> 学完本章：会区分基本类型、转换类型、计算表达式并判断结果。

## 1. 常见数据类型

| 类型 | 名称 | 示例 |
| --- | --- | --- |
| `int` | 整数 | `10`、`-3` |
| `float` | 浮点数 | `3.14` |
| `str` | 字符串 | `"hello"` |
| `bool` | 布尔值 | `True`、`False` |
| `NoneType` | 空值的类型 | `None` |

~~~python
a = 10
b = 3.5
c = "10"
d = True

print(type(a))  # <class 'int'>
print(type(c))  # <class 'str'>
~~~

`"10"` 是字符串，不等于整数 `10`。`True`、`False` 首字母必须大写。

## 2. 类型转换

~~~python
print(int("12"))     # 12
print(float("3.5"))  # 3.5
print(str(12))       # 12（字符串）
print(int(3.9))      # 3：向 0 截断
~~~

`int("3.5")` 会报 `ValueError`，因为字符串 `"3.5"` 不是整数形式；可先转 `float` 再转 `int`。

## 3. 算术运算符

| 运算符 | 含义 | 示例与结果 |
| --- | --- | --- |
| `+` | 加 | `7 + 2 → 9` |
| `-` | 减 | `7 - 2 → 5` |
| `*` | 乘 | `7 * 2 → 14` |
| `/` | 普通除法 | `7 / 2 → 3.5` |
| `//` | 向下取整除法 | `7 // 2 → 3` |
| `%` | 取模 | `7 % 2 → 1` |
| `**` | 幂 | `2 ** 3 → 8` |

注意：负数时 `//` 是向负无穷取整，所以 `-7 // 2` 得到 `-4`，不是 `-3`。

## 4. 比较运算与逻辑运算

~~~python
print(3 > 2)                # True
print(3 == 3)               # True
print(3 != 2)               # True
print(60 <= 80 < 100)       # True

score = 85
print(score >= 60 and score < 90)  # True
print(score < 60 or score == 85)   # True
print(not True)                    # False
~~~

常见比较符号：`>`、`<`、`>=`、`<=`、`==`、`!=`。

- `and`：两边都满足才为真。
- `or`：至少一边为真。
- `not`：取反。

## 5. 优先级、成员运算

先算括号，再算幂、乘除、加减、比较、逻辑运算。复杂表达式建议显式加括号，避免依赖记忆。

~~~python
print(2 + 3 * 4)          # 14
print((2 + 3) * 4)        # 20
print("py" in "python")   # True
print("z" not in "python")  # True
~~~

## 考前记住

- `/` 和 `//` 不同；`//` 会向下取整。
- `%` 取余，`**` 求幂。
- `==` 比较相等，`=` 赋值。
- `input()` 得到字符串，不能直接与整数做加法。
- `in` 判断成员关系；不要把 `is`（身份判断）当作 `==` 使用。

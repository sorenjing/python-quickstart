# 01｜基础语法

> 学完本章：能定义变量、输入和输出，知道缩进与注释的作用。

## 1. 注释和缩进

`#` 后面是单行注释，不会作为代码执行：

~~~python
# 计算两门课的总分
math = 85
english = 90
print(math + english)  # 175
~~~

Python 用**缩进**表示代码块。`if`、`for` 等语句后面需要缩进；同一个代码块通常统一用 **4 个空格**。

~~~python
score = 80

if score >= 60:
    print("及格")

print("判断结束")
~~~

`print("判断结束")` 没有缩进，无论条件真假都会执行。若将缩进写错，可能出现 `IndentationError`。

## 2. 变量与赋值

变量可以理解为**引用一个值的名字**。`=` 是赋值，不是数学上的相等判断：

~~~python
score = 80
score = 90
print(score)  # 90
~~~

变量名常见规则：

- 可由字母、数字、下划线组成，也支持符合规则的 Unicode 字符。
- 不能以数字开头，例如 `2score` 不合法。
- 区分大小写：`score` 与 `Score` 不同。
- 不能使用 `if`、`for`、`class` 等关键字命名。
- 建议使用有意义的小写名称，如 `student_score`。

## 3. 输出 print()

~~~python
name = "小王"
score = 88

print(name, score)               # 小王 88
print("成绩：", score)            # 成绩： 88
print("A", "B", sep="-")         # A-B
print("第一行", end=" ")
print("接在同一行")
~~~

`sep` 控制多个参数之间的分隔符；`end` 控制结尾内容（默认换行）。

## 4. 输入 input()

**`input()` 获取到的内容始终是字符串 `str`，哪怕输入的是数字。**

~~~python
name = input("请输入姓名：")
age = int(input("请输入年龄："))
print(f"{name}今年{age}岁")
~~~

`int()` 将能表示整数的字符串转换为整数。如果输入 `abc`，会因为无法转换而报错。

## 5. 常见语法易错点

| 写法 | 正确吗？ | 原因 |
| --- | --- | --- |
| `user_name = "小王"` | ✓ | 合法变量名 |
| `1score = 90` | ✗ | 不能以数字开头 |
| `if = 3` | ✗ | `if` 是关键字 |
| `score == 60` | ✓ | 比较是否相等，不是赋值 |
| `print("你好")` | ✓ | 正常输出字符串 |

## 考前记住

- `=` 赋值，`==` 比较是否相等。
- Python 代码块依靠缩进区分层级。
- `input()` 返回 `str`；做数值运算前通常要转换类型。
- 字符串字面量需要引号；变量名不用。

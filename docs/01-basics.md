# 01｜变量与输入输出

> 学完这课，你能让程序读一行文字，再把它放进一句问候里。

## 给一段文字起个名字

~~~python
name = "小林"
print("你好，", name, sep="")
~~~

第一行把文字 `"小林"` 交给名字 `name`，这一步叫**赋值**。第二行读取 `name` 对应的文字，把它与 `"你好，"` 一起输出。

~~~text
你好，小林
~~~

`print()` 默认在两项之间加一个空格。这里的 `sep=""` 去掉间隔。试着删掉 `sep=""`，观察输出多了哪个空格。

<h2 id="input-output">让用户输入名字</h2>

把第一行的固定名字换成 `input()`。

~~~python
name = input("请输入名字：")
print("你好，", name, sep="")
~~~

运行后，程序显示提示并等待。输入「小林」并按回车，文字就存进了 `name`。如果题目只要求输出结果，用 `name = input()` 读取，程序就会直接等待输入。

~~~text
请输入名字：小林
你好，小林
~~~

示例的第一行中，「小林」是你键入的文字。程序打印的是第二行问候。即使你输入 `18`，`input()` 得到的也是文字。

## 按题目给的格式输出

`"你好，{}！".format(name)` 会把 `{}` 换成 `name` 的值。输入「小林」时，下面两行会打印 `你好，小林！`。

~~~python
name = input()
print("你好，{}！".format(name))
~~~

`print()` 默认在输出结束后换行。题目要求接着在同一行打印时，可以写 `print("A", end="")`。

<h2 id="names">试着改两处</h2>

- 把最后一行中的 `name` 改成 `"name"` 再运行。带引号时，屏幕会显示英文字母 `name`。
- 加一行 `# 读取用户的名字` 放在程序开头。以 `#` 开头的这一行是注释，运行结果保持一样。三引号圈起来的是字符串。要注释多行代码，可以在每一行前加 `#`。

变量要先赋值才能使用，之后可以重新赋值。变量名可用字母、数字和下划线，数字不能开头。字母大小写有区别，`name` 和 `Name` 是两个名字。像 `if`、`for` 这样被 Python 保留的词不能用作变量名。

<h2 id="self-check">动手练习</h2>

1. 合上示例，自己写一个小程序。读入一行城市名，题目只要求输出一句问候。输入「成都」时，应输出 `你好，成都！`。
2. 判断：`name` 和 `Name` 是否指同一个变量名？

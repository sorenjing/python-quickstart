# 01｜变量与输入输出

> 学完这课，你能让程序读一行文字，再把它放进一句问候里。

## 给一段文字起个名字

~~~python
name = "小林"
print(name)
print("name")
~~~

第一行的 `=` 把右边的值 `"小林"` 交给左边的名字 `name`。这一步叫**赋值**，用来保存值的名字叫**变量名**。

- `print(name)` 读到的是这个名字保存的值，屏幕显示 `小林`。
- `print("name")` 里有引号，屏幕直接显示字母 `name`。

把两个要显示的内容用逗号隔开，`print` 就能依次显示它们。默认会在两项中间加一个空格。用 `sep` 可以指定这个间隔，`""` 是两个紧挨着的引号，表示一段长度为 0 的文字，所以 `sep=""` 让两项直接贴在一起。

~~~python
name = "小林"
print("你好，", name)
print("你好，", name, sep="")
~~~

~~~text
你好， 小林
你好，小林
~~~

<h2 id="input-output">让用户输入名字</h2>

`input` 是 Python 提供的另一个工具。括号里的文字是给用户看的提示。用户输入一行并按回车后，`input` 把读到的文字交出来。`name = input(...)` 会把这段文字保存到 `name`。

~~~python
name = input("请输入名字：")
print("你好，", name, sep="")
~~~

输入「小林」并按回车，可以看到下面的交互。若题目只要求最后的输出，用 `name = input()`，括号里留空就不会额外显示提示。

~~~text
请输入名字：小林
你好，小林
~~~

示例的第一行中，「小林」是你键入的文字。程序打印的是第二行问候。即使你输入 `18`，`input()` 得到的也是文字。

## 按题目给的格式输出

引号里的 `"你好，{}！"` 是一句还没填完的话。`{}` 像空格子，`.format(name)` 取出 `name` 保存的文字放进这个格子。点号前是要填的模板，括号里是填进去的值。最后外层的 `print` 显示填完的整句。输入「小林」时，输出 `你好，小林！`。

~~~python
name = input()
print("你好，{}！".format(name))
~~~

`print()` 默认在输出结束后换行。题目要求接着在同一行打印时，可以写 `print("A", end="")`。

<h2 id="names">试着改两处</h2>

- 把 `.format(name)` 改成 `.format("name")` 再运行。填进去的是字母 `name`，所以整句变成 `你好，name！`。
- 加一行 `# 读取用户的名字` 放在程序开头。以 `#` 开头的这一行是注释，运行结果保持一样。三引号圈起来的是字符串。要注释多行代码，可以在每一行前加 `#`。

变量要先赋值才能使用，之后可以重新赋值。变量名可用字母、数字和下划线，数字不能开头。字母大小写有区别，`name` 和 `Name` 是两个名字。像 `if`、`for` 这样被 Python 保留的词不能用作变量名。

<h2 id="self-check">动手练习</h2>

2. 判断：`name` 和 `Name` 是否指同一个变量名？

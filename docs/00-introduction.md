# 00｜运行第一段 Python

<h2 id="run">运行第一行</h2>

1. 从 [Python 官网](https://www.python.org/downloads/) 安装 Python 3。
2. 用编辑器新建 `hello.py`。文件名末尾的 `.py` 表示这是一个 Python 源代码文件。
3. 写入下面这行并保存。用英文半角括号 `()` 和英文双引号 `""`。键盘上的直引号 `"` 和中文弯引号 `“”` 长得不一样。

~~~python
print("期末加油")
~~~

终端是输入命令并查看文字结果的窗口。在 VS Code 中，打开 `hello.py` 所在的文件夹，再点「终端 → 新建终端」。在终端里输入下面这条命令，然后按回车。

~~~console
python hello.py
~~~

这条命令让 Python 运行 `hello.py` 里的代码。屏幕上会出现一行文字，这叫**输出**。

~~~text
期末加油
~~~

<details>
<summary>命令找不到或文件打不开</summary>
<p>终端找不到 <code>python</code> 时，Windows 可以试 <code>py hello.py</code>，macOS 或 Linux 可以试 <code>python3 hello.py</code>。</p>
<p>如果提示找不到文件，检查文件是不是叫 <code>hello.py</code>，以及终端是否开在保存文件的目录。</p>
</details>

## 拆开看 `print("期末加油")`

| 看到的写法 | 它告诉 Python 什么 |
| --- | --- |
| `print` | 显示内容。Python 已经准备好了这个工具，可以直接用 |
| `(...)` | 把要显示的内容放在左右圆括号之间 |
| `"期末加油"` | 两端的引号标出一段文字从哪里开始、到哪里结束。编程里把这段文字叫**字符串** |

引号是代码里的边界标记。屏幕只显示中间的 `期末加油`，没有两侧的引号。试着把引号中间的 `期末加油` 改成 `你好`，保存并重新运行，输出也会变成 `你好`。

## 看见引号，先找成对的另一边

下面两行只差一对引号。`*` 是代码里写乘法时用的符号。

~~~python
print(2 * 3)
print("2 * 3")
~~~

| 括号里的内容 | Python 怎么处理 | 屏幕显示 |
| --- | --- | --- |
| `2 * 3` | `2` 和 `3` 是两个数，`*` 让 Python 先算乘法 | `6` |
| `"2 * 3"` | 同一对引号包住了数字、空格和星号。Python 把中间的每个字符都当作文字来显示 | `2 * 3` |

读输出题时，先圈出成对的引号，再看哪些符号在引号外、需要计算。

## 认识 Python

- Python 由 Guido van Rossum 创建，1991 年首次公开发布。
- Python 是开源的高级通用编程语言，支持过程式和面向对象等写法。上面执行 `hello.py` 的 Python 程序叫**解释器**。
- Python 采用动态类型。数和文字可以用同一个名字先后保存，第 01 课会通过赋值示例演示。
- 源码区分大小写，并用行首空格表示哪些代码属于同一块。第 03 课会用条件判断来演示。

<h2 id="self-check">先猜结果，再运行</h2>

把文件内容换成下面三行。先看引号包住了哪些字符，再预测每一行的输出。`+` 是做加法时用的符号。

~~~python
print("8")
print(8 + 1)
print("8 + 1")
~~~

<details>
<summary>查看参考答案</summary>
<p>第一行显示 <code>8</code>，它来自一段文字。第二行引号外的两个数参与加法，显示 <code>9</code>。第三行整段都在引号里，按原样显示 <code>8 + 1</code>。</p>
</details>
